# 待测试

- 提示词库在云端没有同步数据或请求失败时，展示 12 条内置创作模板，并支持搜索、分类、标签、复制和加入我的素材。
- 主导航新增“素材库”，未登录也可访问；云端没有素材时展示 12 条内置创作工具素材。
- 配置弹窗新增“查看余额”和“去充值”入口，均跳转到 Z-API 钱包页；画布不保存支付信息。
- 站内“我的钱包”展示可用余额、冻结余额、充值订单和本人最近 100 条钱包流水；支付返回后自动刷新订单与余额，网关异步通知验签成功后原子到账。
- 钱包在线充值改为仅展示支付宝；后端支持支付宝开放平台网页支付 RSA2 下单与异步通知验签，并校验 App ID、订单金额和交易状态。正式可用仍需完成支付宝网站支付签约、密钥配置、应用审核与小额实付验证。
- 支付宝密钥配置完成但网站支付产品尚未签约或应用未审核时，钱包保持关闭并展示真实原因；只有验证完成并设置 `ALIPAY_PAYMENT_ENABLED=true` 后才开放付款按钮。
- 管理后台继续通过用户管理、AI 日志、生成日志和算力点日志查看登录用户及其生图/视频调用，普通用户无权访问。
- 模型广场由后端目录提供 24 张模型卡、59 个档位，并按热门、大语言模型、图片、视频、人物、音乐、语音、3D 和工具分类；未配置线路的档位显示“待接入”，不会假装可用。
- 新增 `Providers + Models + Routes` 管理页，可保存供应商 Base URL 和自有模型到实际上游模型 ID 的线路映射；上游 API Key 只来自服务器 Secret，后台仅显示是否已配置。
- 模型广场点击可用卡片后，应把自有模型 ID 写入画布配置并打开画布；用户界面不显示供应商名称和实际上游模型 ID。
- JSON 与 multipart 请求使用档位 ID 时，后端应按启用线路解析供应商并替换为实际上游模型 ID；同步图片、音频和异步视频创建会按线路优先级尝试主备线路，只对收到明确 408/425/429/5xx 响应的创建请求切换，连接中断等结果不确定的错误不自动重试。
- 模型卡片的分辨率、时长、比例、模式或价格为 `null` 时，前端 API 层应统一转换为空数组，音频和工具模型不再导致模型广场整页崩溃。
- 用户钱包、顶部余额、画布生成按钮和模型广场统一使用人民币显示；内部继续以人民币分整数记账，充值金额与到账余额一比一，不再向用户展示算力点。
- 模型广场新增 GPT Image 2 默认/2K/4K/Pro 4K、Midjourney 标准/Turbo 和 Wan Ultra Fast 10 秒独立卡片，并按已确定的薄利售价展示；这里只录用户售价，未核实成本不向用户展示。
- 模型广场目录升级为热门、大语言模型、图片、视频、人物/数字人、音乐、语音、3D、AI 工具；语言模型同时展示输入和输出的每百万 Token 售价，其余模型按张、次或秒展示人民币售价。
- 模型广场以“最终接入定价”表为唯一默认目录，收口为 24 张模型卡和 59 个档位；同一模型只显示一张卡，用户在卡片内选择具体档位。
- 后台预建且只允许 302.AI、WaveSpeed、LEC、seedance.nz 四家供应商；59 个档位的默认线路均保持停用，管理员填写真实 Base URL/API Key 并测试后再启用。
- 公开模型广场接口只返回前台名称、档位、售价和可用状态，不返回供应商代码、上游 Model ID、成本价或上游 Key。
- 普通用户保存模型配置时会强制使用平台云端模式并删除本地 API Key/Base URL/本地渠道；普通用户提交本地渠道请求会被后端拒绝，本地参数转译接口仅管理员可访问。
- 管理后台“模型与路由”新增档位售价/上下架编辑，并将线路配置改为精确关联模型档位。
- 异步视频任务应以公开档位 ID 记账并返回给用户，同时只在服务器任务记录中保存真实上游模型 ID；轮询继续使用上游模型，普通用户响应不返回渠道名称、渠道 ID、上游模型或原始请求体。
- 供应商即使被管理员设为启用，Base URL 或 API Key 为空时也不得使模型档位显示为可用；动态成本档位在真实结算未实现前不得生成。
- 目录版本升级后，四家上游遗留在 `model_providers.api_key` 的明文应被清空；分别用 `MODEL_PROVIDER_302_API_KEY`、`MODEL_PROVIDER_WAVESPEED_API_KEY`、`MODEL_PROVIDER_LEC_API_KEY`、`MODEL_PROVIDER_SEEDANCE_NZ_API_KEY` 提供服务器密钥。
- 用户钱包新增可用余额与冻结余额；生成前原子冻结售价，成功后结算，失败后解冻，重复任务回调通过账务流水 ID 保持幂等，不得重复扣款或退款。
- 同步图片、音频和工作流 Agent 请求，以及异步视频创建与轮询，均应使用同一套冻结、结算、解冻流程；异步视频在最终状态出现前保持冻结。
- 管理员新增“生成任务”页面，可查看最近图片、视频、音频任务的用户、公开模型档位、任务状态、资金状态、售价、结果和错误；普通用户无权访问该接口。
- 钱包流水后台改为只读，展示可用余额与冻结余额两组变动；管理员仍只能通过用户余额调整或充值审核产生受控流水。
- 视频任务完成记录保留 30 天以供后台追踪；Base64 或本地对象地址不作为管理员可点击的结果链接返回，避免把大块媒体数据塞入管理接口。
- 同一套站点按 `admin` / `user` 角色展示不同能力：管理员可使用普通画布并额外进入管理后台，普通用户只使用平台云端渠道且看不到上游 Key。
- 管理后台首页改为“财务中心”，展示今日与累计充值到账、生成结算收入、失败解冻、用户可用余额和任务冻结余额；未取得上游真实成本前明确不展示利润或伪造供应商余额。
- [ ] 修改 Render `ADMIN_PASSWORD` 后重新部署，确认数据库中的 `admin` 管理员密码同步更新，并可进入 `/admin/finance`。
- 管理后台新增独立“中转站管理”页面，集中展示四家上游的 Base URL、服务器 Key 配置状态、启用线路数、手工核实余额和黄/红/极低余额预警；没有余额记录时显示“需要登录上游查看”。
- “模型与路由”新增完整模型管理：管理员可编辑模型名称、分类、描述、热门推荐、运行状态、排序和模型广场上下架；已隐藏模型仍保留在管理员列表中并可重新上架，档位售价改为直接填写人民币。
- 画布图片和音频使用模型广场档位时不再错误要求旧版渠道 ID；生成应直接使用后台启用的路由，所有线路失败后只解冻一次。
- 图片和音频任务超过 10 分钟、视频任务超过 30 分钟仍未完成时，后台应自动标记失败并解冻对应资金，服务重启后扫描仍然生效。
- 管理后台“生成任务”支持按关键字、类型、任务状态、资金状态和创建日期筛选；关键字可匹配任务、用户、模型、来源和错误信息。
- “模型与路由”新增上线检查，可汇总可用供应商、已上架档位、可生成档位、启用线路和当前阻塞项；缺少固定售价、上游 ID、Base URL、服务器 Secret 或供应商未启用时，后台禁止误启用线路。
- 画布模型选择器按图片、视频、文本和音频展示模型广场中真正可用的档位；旧节点保存的失效模型会回退到该类别当前首个可用档位，生成按钮读取模型广场人民币售价，不再显示旧模型或 ¥0.00。
- 管理后台“模型与路由”任一资料接口失败时，其余中转站、模型、档位和线路仍应独立显示，并明确提示具体失败项，不再因一个请求失败整页显示 0。
- 中转站连接测试返回模型 ID 时，后台应弹窗列出实际上游模型清单；清单不显示 API Key，可用于逐个核对尚未接入的真实线路。
